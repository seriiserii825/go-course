# Создание первого проекта

Создадим папку:

```bash
mkdir -p ~/Documents/go/hello
cd ~/Documents/go/hello
```

Инициализируем проект:

```bash
go mod init example.com/hello
```

Появится файл go.mod:

```bash
module example.com/hello
```

example.com/hello — идентификатор модуля. Это не обязательно существующий сайт.
В JavaScript аналогом будет:
npm init -y

Go JavaScript

```bash
go.mod package.json
go mod tidy Частично аналог управления зависимостями
go run . node index.js
go build Сборка приложения
go get Добавление или обновление зависимостей
```

## Запуск и компиляция

Запуск без сохранения исполняемого файла

```bash
go run .
```

Go компилирует и запускает программу во временном расположении.

Компиляция в бинарный файл

```bash
go build -o hello .
./hello
```

Получишь самостоятельный исполняемый файл hello, которому не требуется установленный Go.

## Компиляция для Windows из Linux

```bash
GOOS=windows GOARCH=amd64 go build -o hello.exe .
```

Для обычной Go-программы без C-зависимостей можно собирать бинарники для других ОС.

В отличие от Node.js, Go не требует node_modules внутри каждого проекта.
Зависимости обычно кэшируются глобально.
