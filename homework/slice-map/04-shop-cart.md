# Проект 4: Корзина покупок с акциями

## Задача

Смоделировать корзину покупок в интернет-магазине. Каталог товаров — `map[string]float64` (название товара → цена за штуку). Корзина — `map[string]int` (название товара → количество).

В магазине действуют две акции:
- «3 по цене 2»: если товара в корзине 3 штуки или больше, одна из каждых трёх предоставляется бесплатно (например, 7 штук → платим за 5);
- скидка постоянного клиента: если итоговая сумма чека (после акции «3 по цене 2») превышает заданный порог, дополнительно вычитается процент скидки от суммы.

Реализовать функции:
- добавление товара в корзину (если товара нет в каталоге — вернуть ошибку `error`);
- расчёт стоимости одной позиции с учётом акции «3 по цене 2»;
- формирование чека — `[]Item`, где `Item` хранит название, количество, цену за штуку и итоговую стоимость позиции со скидкой;
- расчёт полной суммы чека с применением скидки постоянного клиента;
- поиск самой дорогой позиции в чеке (по итоговой стоимости).

## Результат

- Тип `Item struct { Name string; Qty int; Price float64; Total float64 }`.
- Функция `AddToCart(cart map[string]int, catalog map[string]float64, name string, qty int) error` — добавляет товар в корзину, проверяя его наличие в каталоге.
- Функция `LineTotal(price float64, qty int) float64` — стоимость позиции с учётом акции «3 по цене 2».
- Функция `BuildReceipt(cart map[string]int, catalog map[string]float64) []Item` — чек по корзине, отсортированный по названию товара.
- Функция `GrandTotal(receipt []Item, loyaltyThreshold float64, loyaltyPercent float64) float64` — итоговая сумма чека с учётом скидки постоянного клиента.
- Функция `MostExpensiveItem(receipt []Item) Item` — позиция с наибольшей итоговой стоимостью.
- `main()` с каталогом из минимум 5 товаров и корзиной, где хотя бы у одного товара количество достаточно для срабатывания акции «3 по цене 2», а итоговая сумма — для срабатывания скидки постоянного клиента. Продемонстрировать работу всех функций, включая попытку добавить товар, которого нет в каталоге.
