# Проект 5: Группировка анаграмм

## Задача

Написать программу, которая группирует слова-анаграммы (слова, состоящие из одних и тех же букв в разном порядке).

Использовать `map[string][]string`, где ключ — отсортированные буквы слова (своеобразная "подпись" анаграммы), а значение — slice всех слов с такой подписью.

Реализовать функции:
- построение подписи слова (отсортировать буквы слова и собрать обратно в строку);
- группировка списка слов в map анаграмм;
- получение только тех групп, где больше одного слова (результат — `[][]string`).

## Результат

- Функция `Signature(word string) string` — отсортированные буквы слова как строка.
- Функция `GroupAnagrams(words []string) map[string][]string` — группирует слова по подписи.
- Функция `OnlyGroups(groups map[string][]string) [][]string` — оставляет только группы из двух и более слов.
- `main()` с минимум 10 словами (среди которых есть несколько групп анаграмм и несколько одиночных слов), демонстрирующий работу всех трёх функций и вывод результата через `fmt.Println`.
