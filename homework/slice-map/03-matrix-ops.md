# Проект 3: Операции с матрицей

## Задача

Поработать с двумерным slice (`[][]int`) как с матрицей.

Реализовать функции:
- транспонирование матрицы (строки становятся столбцами);
- сложение двух матриц одинакового размера;
- поиск максимального элемента во всей матрице;
- вычисление суммы элементов каждой строки (результат — `[]int`).

Матрицы в заданиях должны создаваться динамически через `make`, а не быть заранее зашитыми константами (кроме входных данных, которые передаются в функцию).

## Результат

- Функция `Transpose(m [][]int) [][]int` — возвращает транспонированную матрицу.
- Функция `Add(a, b [][]int) [][]int` — поэлементная сумма двух матриц.
- Функция `MaxElement(m [][]int) int` — максимальный элемент матрицы.
- Функция `RowSums(m [][]int) []int` — сумма элементов каждой строки.
- `main()`, демонстрирующий все четыре функции на матрице минимум 3x3, с выводом результатов через `fmt.Println` в удобочитаемом виде (построчно).
