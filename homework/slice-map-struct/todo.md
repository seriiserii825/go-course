# Практика Go — Product Inventory CLI

## Цель

Создать CLI-программу для управления товарами на складе.

Использовать `struct`, `slice`, `map`, функции и стандартную библиотеку Go.

## 1. Структура проекта

```text
product-inventory/
├── main.go
├── models/
│   └── product.go
└── inventory/
    ├── products.go
    ├── search.go
    ├── statistics.go
    └── categories.go
```

## 2. План реализации

### 1. Модель товара — models/product.go

- [x] Создать `struct Product`.
- [x] Добавить поля: `ID`, `Name`, `Price`, `Quantity`, `Category`.
- [x] Подобрать подходящие типы данных.

### 2. Список товаров — inventory/products.go

- [x] Создать slice из 5 товаров в `main.go`.
- [x] Создать функцию вывода всех товаров.
- [x] Использовать `for range` для перебора.

### 3. Поиск и фильтрация — inventory/search.go

- [x] Создать функцию поиска товара по ID.
- [x] Обработать ситуацию, когда товар не найден.
- [x] Создать функцию фильтрации товаров дороже $100.

### 4. Статистика — inventory/statistics.go

### 7. Запуск программы — main.go

- [ ] Создать 5 тестовых товаров.
- [ ] Вызвать функции из пакета `inventory`.
- [ ] Вывести результаты каждой операции в терминал.
- [ ] Проверить корректность работы программы.

## 3. Условия

- Использовать отдельные функции для каждой операции.
- Разделить код по пакетам `models` и `inventory`.
- Не использовать глобальные переменные для хранения товаров.
- Не использовать сторонние библиотеки.
- Предусмотреть обработку пустого slice.
- Функции должны возвращать результаты, а не только выводить их.
