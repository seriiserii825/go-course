# 9. Практическое задание

Создай папку 02-variables в своём репозитории go-course.

go-course/
├── go.mod
├── 01-go-install/
│ └── main.go
└── 02-variables/
└── main.go
Новый go mod init не нужен: обе папки находятся внутри одного Go-модуля.

Напиши программу, которая:

Создаёт переменные name, age, language, experience, isLearning.

Использует минимум три разных типа данных.

Выводит значения переменных через fmt.Printf.

Выводит тип каждой переменной через %T.

Увеличивает experience на 1.

Объявляет константу courseName со значением "Go Course".

Пример ожидаемого результата:

Course: Go Course
Name: Sergey
Age: 30
Language: Go
Experience: 2
Learning: true

Types:
name: string
age: int
language: string
experience: int
isLearning: bool
Запуск:

go run ./02-variables

Дополнительное задание: объяви две переменные a = 10 и b = 20, поменяй их значения местами без третьей переменной.
