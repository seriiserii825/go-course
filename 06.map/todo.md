# Склад товаров — Map

Напиши программу на Go для управления остатками товаров на складе
интернет-магазина с помощью map.

## Начальные данные

Ключ — название товара, значение — количество на складе.

## Задания

- [ ] Выведи все товары и их количество через `for range`.
- [ ] Добавь новый товар `Webcam` с количеством 10.
- [ ] Поступила новая партия: добавь 15 единиц `Mouse` к существующему
      количеству.
- [ ] Покупатель заказал 3 `Laptop` — уменьши остаток на 3.
- [ ] Полностью удали `Headset` со склада через `delete()`.
- [ ] Проверь, существует ли товар `Monitor`, используя `value, exists`.
- [ ] Найди товар с самым большим количеством на складе.
- [ ] Посчитай общее количество единиц всех товаров.
- [ ] Выведи количество разных товаров через `len()`.

Выполнено: 0 из 9
